# 小松绿桌宠 🌱

一个基于 **Godot 4.6** 的 Windows 桌面宠物，以虚拟主播**小松绿**的 AI 绘制二创形象为原型。
支持养成数值、打字互动、喂食演出，常驻桌面、鼠标穿透，不挡任何操作。

## ✨ 功能

- 🖥️ 全屏透明层实现，置顶显示，角色轮廓外鼠标穿透
- 🖱️ 按住拖动换位置（被拎起动画），单击触发随机情绪动画
- ⌨️ 全局键盘监听：在**任何窗口**打字，桌宠头顶都会弹出字母雨 + 随机 emoji 彩蛋
- 🍳 **喂食交互**：右键菜单投喂后，食物会挂在鼠标上跟着走，桌宠自己走过来，点击它完成投喂（滑入嘴 + 咀嚼 + 欢呼全套演出）
- 📊 **养成数值**：精力 / 心情 / 亲密度 + 食物系统，每 20 秒自动结算
  - 正常打字就攒食物进度，攒满获得食物
  - 30 秒内敲 80 键触发「敲得欢」
  - 60 秒不理它，它会睡着（任意互动唤醒）
  - 数值状态影响它的自动行为：心情低会哭、精力低不爱动
- 📋 右键菜单：投喂一份 / 每日报告（带数值进度条）/ 气泡开关 / 退出
- 💾 自动存档；离线再回来精力自动回满，不做惩罚设计

## 🎮 交互方式

| 操作 | 反应 |
|---|---|
| 在任意窗口打字 | 字母雨，攒敲击数和食物进度 |
| 30 秒内敲 80 键 | 敲得欢（欢呼 + 心情提升） |
| 单击角色 | 随机情绪动画，心情 +3 |
| 按住角色拖动 | 换位置，心情 +1 |
| 右键角色 | 打开菜单 |
| 60 秒无任何操作 | 睡着，敲键盘/点击/拖动唤醒 |

## 🛠️ 构建与运行

1. 安装 [Godot 4.6.1 .NET 版](https://godotengine.org/download) 与 .NET SDK 8
2. 用 Godot 打开本工程（`project.godot`），首次打开会重建导入缓存，等待即可
3. 编辑器内 F5 直接运行；或通过「项目 → 导出」导出 Windows 版

> - 运行导出版需要目标机器安装 [.NET Desktop Runtime 8](https://dotnet.microsoft.com/download/dotnet/8.0)
> - 存档位置：`%APPDATA%\Godot\app_userdata\小松绿桌宠\save.json`
> - 调试版导出自带控制台窗口；正式分发时在导出预设里关掉「调试 + 控制台封装」
